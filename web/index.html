Taking BitBot somewhere new
  1. Switch on, then hold the onboard BOOT button for 3 seconds. RESET just restarts the robot.
  2. Join the BitBot-XXXX hotspot with its setup password. For this first firmware, find it on USB serial.
  3. Open http://192.168.4.1 if setup does not open automatically. Stay on the hotspot even if your phone reports no internet.
  4. Add the new Wi-Fi, then choose Finish setup. Your personality and other networks stay saved.

A 2.4 GHz phone hotspot also works. Hotel login pages and enterprise Wi-Fi need a different connection method.

Where are my settings stored?

On the robot, settings and credentials are stored in its flash. This development build does not yet encrypt flash storage. The setup hotspot is password-protected and closes when setup is finished.

In the desktop simulator, data is saved locally on this computer. No cloud service is called. Use dummy passwords and API keys.
